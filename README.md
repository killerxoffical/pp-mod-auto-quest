# 🎮 Google Play Games Achievement Unlocker (Self-Hosted)
**VAREON Studio • 100% Free Engine**

---

### 📌 এটি কী?
এটি একটি নিজস্ব, লাইটওয়েট পাইথন ইঞ্জিন যা কোনো থার্ড-পার্টি টেলিগ্রাম বট ছাড়াই সরাসরি গুগল প্লে গেমস সার্ভিসেস (GPGS) এপিআই (`games.googleapis.com`) ব্যবহার করে গেমের এচিভমেন্ট ও প্লে পয়েন্ট আনলক করতে পারে।

---

### 📂 ফাইল পরিচিতি:
* `config.py`: গুগল প্লে গেমস এপিআই এবং প্যাকেজ সংক্রান্ত কনফিগারেশন।
* `auth.py`: `gpsoauth` ব্যবহার করে গুগলের মাস্টার লগইন ও OAuth2 বিয়ারার টোকেন জেনারেটর।
* `engine.py`: গুগল এপিআই দিয়ে প্লেয়ার প্রোফাইল চেক, এচিভমেন্ট লিস্ট এবং আনলক করার কোর ইঞ্জিন।
* `games_db.py`: বিভিন্ন গেমের প্যাকেজ ও এচিভমেন্ট ডেটাবেজ।
* `test_runner.py`: একটি টেস্ট অ্যাকাউন্ট দিয়ে সরাসরি টেস্ট করার ইন্টারেক্টিভ স্ক্রিপ্ট।

---

### 🚀 টেস্ট করার নিয়ম:
১. কমান্ড প্রম্পট বা টার্মিনালে এই ফোল্ডারে ঢুকুন:
```bash
cd achievement_unlocker
```
২. টেস্ট স্ক্রিপ্ট রান করুন:
```bash
python test_runner.py
```
৩. আপনার একটি টেস্ট গুগল অ্যাকাউন্টের জিমেইল ও পাসওয়ার্ড (বা 2-Step অন থাকলে ১৬ অক্ষরের Google App Password) দিয়ে এন্টার দিন।

সফল হলে এটি গুগলের সাথে সরাসরি যোগাযোগ করে আপনার প্লেয়ার গেমার ট্যাগ, আইডি এবং এচিভমেন্ট স্ট্যাটাস প্রদর্শন করবে!
